About this record

A daily pre-market briefing, built and run as a learning project. Each weekday morning a script gathers futures, sector ETF and 10-year yield data from yfinance, headlines from public RSS feeds published in the previous 72 hours, and cycle counts for anchors I have confirmed. One model call writes the Morning Read from that data. Each page is generated from the same snapshot the morning email used and is published without edits.

The Morning Read is model output, not my call. Every page names the model and prompt version that produced it. Cycle counts appear only for confirmed anchors; unconfirmed anchors are tracked privately and not shown.

Research, not investment advice. Nothing here is a recommendation to buy or sell.

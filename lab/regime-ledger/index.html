About this record

An append-only record of two daily regime reports: Market Regime Watch and Metals Regime Watch. Each report is generated by a scheduled LLM task, not written by me. The Ledger stores what each report said on each date, verifies it against a checksum of the original file, and shows what changed between consecutive observations.

These are not King Nuggets cycle calls. The reports deliberately exclude King Nuggets methodology — no Bressert cycle counts, no RSI-3M3, no COT/Blees ratings. The Ledger records; it does not endorse or reinterpret. If a report says “correction,” the Ledger says “correction.”

The value is in the record, not any single reading. Kept over time, it shows whether a daily LLM regime series is stable enough to build on.

State legend

■ Running

In production. A row may only sit here with evidence attached and a verification date inside the current window.

□ Specced

Designed and written down, not built. No metrics, no track record, no verification date.

— Parked

Deferred on purpose. The reason is stated in the row; a parked system is not a failed one.

State is set by glyph, weight and indent. It is never encoded in colour.
